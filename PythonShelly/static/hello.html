Python-Shelly Project

About the Project

This project, named Python-Shelly, is part of the BIS6-Building Secure Architecture course.

This application tries to replicate the functions of a Shelly Door/Window2.

Features

  • HTTP API configuration

Technologies Used

  • Python
  • HTML

Differences

This project is a simulation of the Shelly Door/Window2; it does not have the exact same functionalities as the original product.

The "/settings/actions" endpoint (might) works differently than the real one.

To use this endpoint, take the action you want to modify, add "_", and the name of the parameter you want to modify.

Example: dark_url + enabled = dark_url_enabled

/settings/actions?dark_url_enabled=true

Examples for use

To use the API, you can send GET requests to the following endpoints:

  • http://127.0.0.1:5000/status - Get current status
  • http://127.0.0.1:5000/settings?temperature_unit=C - Set temperature unit to Celsius
  • http://127.0.0.1:5000/settings/actions?close_url_enabled=true - Enable close URL action
